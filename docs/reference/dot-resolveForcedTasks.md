# Resolve Which Tasks to Force-Rerun

Resolve Which Tasks to Force-Rerun

## Usage

``` r
.resolveForcedTasks(forceRerun, taskFiles)
```

## Arguments

- forceRerun:

  Logical flag or character vector of task file names.

- taskFiles:

  Character. Task file names in this pipeline run.

## Value

Character vector of task file names to run without the rerun check.
